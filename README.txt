# LEVEL UP — Site Motivacional RPG

Abra `index.html` no navegador.

Recursos:
- XP por missão
- XP com valores diferentes por desafio
- Level Up automático
- +3 pontos de status por nível
- Força, Inteligência, Vitalidade e Estamina
- Avatar que evolui a cada 15 níveis (até 6 estágios)
- Missões personalizadas
- Histórico de recompensas
- Progresso salvo no navegador com localStorage
- Interface preta com detalhes roxos e responsiva para celular

Para publicar no GitHub Pages, envie os três arquivos (index.html, style.css e script.js) para um repositório e ative Pages.
